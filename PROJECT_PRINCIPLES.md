# Project Principles

## Mission

Build the most realistic football match simulation engine possible.

---

## Core Principles

1. Simulate football, don't just predict scores.
2. Every prediction must be explainable.
3. Every new feature must improve measurable performance.
4. Architecture comes before implementation.
5. Keep the system modular.
6. Automate everything that can be automated.
7. Data quality is more important than model complexity.
8. Decisions are based on evidence, not assumptions.

---

## Development Philosophy

Build a strong foundation first.
Improve the model step by step.
Never sacrifice quality for speed.
